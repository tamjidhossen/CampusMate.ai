Problem Title
CampusMate.ai: Intelligent Campus Assistant and Emergency Volunteer Network
Problem Description
Universities often have complex communication challenges. General
information, notices, announcements, and emergency requests are scattered
across websites, facebook groups, emails, and noticeboards, making it difficult
for students, teachers, and staff to access relevant information quickly.
Additionally, in-campus emergencies such as medical needs, urgent help
requests, or logistical assistance require immediate coordination, but there is no
centralized system to connect willing volunteers with those in need. Traditional
methods are slow, manual, and error-prone, resulting in delayed responses and
information gaps.
Proposed Solution
CampusMate.ai is a university-exclusive intelligent assistant designed to
streamline communication, automate information delivery, and facilitate
emergency volunteer coordination. The solution comprises three main features:
1. RAG-Powered Chatbot: Using Retrieval-Augmented Generation (RAG), the
chatbot answers university-related questions, including contact
information, policies, procedures, and common inquiries. Answers are
backed by official sources for reliability.
2. Personalized Notice Delivery: The system automatically scrapes and
classifies university notices and delivers to appropriate user/users. Users
create profiles specifying role(teacher/ student/ stuff...), department,
residence, and so on. Notices are delivered based on relevance, e.g., “NOC
for Teacher X of Dept Y,” “Exam routine for Semester 2, Dept X, Session Y,”
etc. Users can query details of any notice directly via the chatbot.
3. Emergency Volunteer Network: When a request is posted, all volunteers are
notified. Volunteers can respond to express interest. The system displays
the number of volunteers who have responded, enabling transparency
and collective coordination. The bot then facilitates secure contact
between the requester and volunteers, ensuring rapid and organized
assistance.
Technologies to Be Used
· Frontend: React + Tailwind and ShadCN
· Backend: Node.js (Express), python
· Database: MongoDB
· Vector Database: ChromaDB
· RAG/LLM: LangChain, LangGraph, Ollama, Gemini LLM (OCR, and
transcription)
· Automation: n8n
· Containerization & Deployment: Docker
· API Testing & Version Control: Postman, Git/GitHub
Expected Outcome/Impact
· Instant and Targeted Communication: Users receive relevant notices
immediately, ensuring no one misses critical updates and improving
overall engagement.
· Trusted Information Access: The RAG-powered chatbot provides accurate,
verified answers, reducing confusion and reliance on unofficial sources.
· Collaborative Volunteer Response: Multiple volunteers can view and
respond to emergency requests, creating a transparent, coordinated, and
efficient support system.
· Stronger Campus Community: Centralized access to information and
volunteer networks enhances collaboration, fosters safety, and empowers
students, staff, and teachers to support each other.
